# Airbnb Data Analytics Dashboard

A professional Business Intelligence project built using Microsoft Power BI and a Star Schema data model to analyze Airbnb listing data.

This project converts Airbnb data into an interactive analytics solution that provides insights into property performance, pricing trends, customer reviews, locations, host performance, and booking patterns.

---

## Project Overview

The objective of this project is to build an end-to-end data analytics solution by:

- Preparing and organizing Airbnb data
- Designing a scalable Star Schema data model
- Creating analytical measures using DAX
- Developing interactive Power BI dashboards
- Extracting meaningful business insights

The dashboard helps stakeholders analyze property performance, guest behavior, host activity, and market trends.

# Data Model Architecture

The project follows a Star Schema approach.

A Star Schema consists of:

- Central Fact Table containing measurable values
- Multiple Dimension Tables containing descriptive information

This structure allows efficient filtering, reporting, and advanced analytics.

---

# Fact Table

The Fact table contains measurable business metrics.

Key metrics include:

- Listing count
- Price information
- Reviews
- Availability
- Revenue-related metrics
- Booking performance indicators
